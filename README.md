Hi, I'm James. I'm based in New Zealand and about to start a Master of Software Development.

I learn by picking projects that are a bit too hard for me and writing down what happens.

**[fury-server-re](https://github.com/Jamerlybob/fury-server-re)**: rebuilding the server for a 2007 Unreal Engine 3 MMO from nothing but the retail client. The network protocol is reverse-engineered from the binary with Ghidra and Frida, and a C# server speaks it well enough that an unmodified client logs in and walks around. The whole thing is written up as a [devlog](https://jamerlybob.github.io/fury-devlog/).

**[signal-exec](https://github.com/Jamerlybob/signal-exec)**: an execution engine that turns trade alerts into broker orders, built around what goes wrong when a broker does not answer, and a method for backtesting alert-following without fooling yourself. Python.
